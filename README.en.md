# Face Recognition Management

A full-stack face recognition management application with a React interface, a Node.js/Express backend following MVC, and browser-based recognition using FaceAPI.

## Front end
- CRUD for registered faces and users
- Charts and data tables
- Basic JWT login and private routes
- Responsive Bootstrap interface and dark theme

## Back end
- Node.js and Express
- Sequelize and MySQL
- MVC controllers, routes, and models

## Recognition
- JavaScript and FaceAPI

## Run
The repository contains separate front-end and back-end components. Install dependencies in each module and configure the MySQL environment for the API before starting the services.
